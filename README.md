
Project Name - বাজার দর (BazarDor)


Project Short Description -

BazarDor is a web-based market price tracking application that helps users explore daily prices of essential commodities in Bangladesh. Users can compare prices across different markets, view price changes over time, and make informed purchasing decisions.



Technologies Used -

1 Next.js — React framework for building the application
2 React.js — Component-based user interface
3 Tailwind CSS — Styling and responsive design
4 DaisyUI — for UI components
5 Better Auth — User authentication
6 API — Fetching product and market price data
7 React Toastify — Notifications and user feedback
8 React Icons — Icons for the user interface


Key Features -

1 Daily Market Prices: View current prices of essential commodities in Bangladesh.
2 Category-Based Browsing: Explore products by categories such as vegetables and other daily necessities.
3 Market Price Comparison: Compare minimum and maximum prices across different markets.
4 Price Change Tracking: View price increases and decreases with percentage indicators and historical price information.
5 User Authentication: Sign up, sign in, and access protected pages, with Google and GitHub social login integration.
